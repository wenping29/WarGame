# 兵棋引擎·后续机制开发参考（遗留建议归档）

> 用途：各战役史料文档「建议机制 / 建议附加机制 / 模板对应建议」章节中，**无法仅靠现有剧本 JSON 落地、需要引擎侧新增能力**的内容，统一归档于此，供后续机制开发排期参考。
> 来源：17 篇战役回合阶段文档 + 《剧本史实数据更新报告-20261019.md》§遗留建议。
> 现状基线：引擎 `VictoryCond.Kind` 当前仅支持 `annihilate`(歼灭比例) / `capture`(独占要点格 q,r) / `nodes`(同时掌握 N 处要点) / `survive`(撑满回合) 四种；胜利判定在 `TurnResolver` 按 kind 分支。事件、多图、受控行动尚无统一框架。

---

## A. 胜利判定新类型（需 `TurnResolver` 新增 kind 分支）

### A1. `withdraw` 突围/撤离胜利（红方主动撤离计分）
- 来源剧本：**徐州会战** `xuzhou/red`、**中条山** `zhongtiaoshan/red`、**九一八** `mukden/red`
- 现状缺口：`survive` 只判"存活到 N 回合"，无法表达"带建制撤出图边缘"这一史实主线（徐州 T13 徐州陷落但主力突围、中条山 T8 后残部突围约十万、九一八赵镇藩按演习路线有序撤退）。
- 建议语义：
  - `kind: "withdraw"`，字段 `side` + `edge`(撤离带: west/east/north/south) + `ratio`(撤离单位占初始比例, 如 0.5/0.7) + `beforeTurn`(须在 T_n 前完成)
  - 判定：到 `beforeTurn` 时，处于指定边缘带的单位数 / 初始单位数 ≥ `ratio` → 该方达成撤离胜利。
  - 中条山特例：三条路线（西渡/南渡/太岳转移）各自独立判定，任一达标即计"突围成功"，成功单位保留进入后续叙事（见 D/E）。
  - 徐州特例：`ratio: 0.7`、撤离带 west/south、`beforeTurn: 13`。
  - 九一八特例：按 T5—T7 经东门撤出单位数计分（与 `survive 12` 并存）。

### A2. `capture` 不立即判负（主动弃守≠战败）
- 来源剧本：**武汉会战** `wuhan/red`
- 现状缺口：蓝方 `capture 5,10` 目前一旦达成即判蓝胜，但史实武汉为"主动弃守、以空间换时间"，红方 `survive` 至 T14 应得主要分数而非判负。
- 建议语义：胜利评估增加"条件优先级"——若一方已满足其 `survive` 条件，对方的 `capture` 不再触发即时失败，仅作为对方得分项计入终局结算。

### A3. `no_resist` 不抵抗枷锁（受控行动约束，非纯胜利条件）
- 来源剧本：**九一八** `mukden/red`
- 现状缺口：引擎无"禁止某方主动开火"的全局约束，也无"每回合掷骰解锁违令"机制。
- 建议语义（属于 B 类全局规则，但影响胜负评估）：
  - T1—T3 红方单位默认 `canFire=false`，每回合士气惩罚递增；
  - 每回合开始掷骰，红方任一单位可"违令还击"（解锁全旅 `canFire`，但触发历史偏离代价标记）；
  - 该约束在 T4 自动解除（张学良令）。
- 配套数值：`mukden` 红 155 分 vs 蓝 145 分近似对等预算，需用士气/禁令修正补偿，否则不复现"兵力 10:1 却战力打折"的史实倒置。

## B. 全局规则 / 状态机（需引擎新增约束框架）

| 规则 | 剧本 | 引擎缺口 | 建议实现 |
|---|---|---|---|
| 不抵抗枷锁 | 九一八 | 行动约束 + 掷骰解锁 | 见 A3 |

## C. 事件卡机制（需引擎新增事件框架：抽取/触发/效果结算）

当前引擎无统一事件系统，以下均需"回合事件表 + 抽取 + 战损/士气/状态效果"支持。

### C1. 外围纵深事件链（多剧本通用）
- **武汉会战** T1—T8 每回合抽取"外围要塞事件"（马当失守/富金山歼敌万余/田家镇失守/潢川迟滞）——红方以额外战损换取蓝方推进延后。
- **徐州会战** T4 临沂/滕县、T9—T11 西迂回四路（第 14 师团兰封封口）、T15 兰封会战。
- **中条山** T1 斩首/特务事件、T4 八路军破袭事件、T6 渡口封锁事件。
- **豫东** T1 开进、T2 阻援四路、T6 蒋军三路反扑。

### C2. 具名事件卡
- **敢死队事件卡**（台儿庄）：红方最多 1 单位转敢死队（攻击+士气代价），达成触发士气脉冲。
- **"一个苹果"事件卡**（上甘岭）：运输单位穿越封锁区送抵补给触发士气回涨。
- **毒气事件卡**（石牌）：蓝方掷骰触发催泪瓦斯，红方无防化受士气/战力惩罚。
- **九国公约时钟**（淞沪）：T9 触发"再坚持两周"，坚守至 T11 后遭金山卫夹击高风险。
- **蒋介石远程微操**（豫东）：T9 亲临督战，蓝方一线强制进攻但指挥扣减。
- **缴获清单事件**（九一八）：蓝方占兵工厂/机场格一次性获大量补给分。

## E. 局部特则 / 状态机（地形、兵种、据点，部分可纯数据、部分需引擎）

- **坑道双层状态**（上甘岭）：表面阵地被逐出→转"坑道态"（半隐蔽、缓损补、可夜袭），`survive` 计数继续——兵棋化核心；需单位状态机。
- **昼夜反差**（上甘岭）：白天蓝炮空压制、夜间红反击窗口——需 `night` 时段行动系数。
- **山地仰攻减益 + 白刃战判定**（石牌）：山地格机动减半、接触后强制近战结算——地形+兵种规则。
- **要塞江防炮**（石牌）：海军炮台对江面/北岸远程压制——远程火力单位。
- **反八字剪刀阵地**（武汉）：正面 fort 红方减益、侧翼迂回触发伏击——地形联动。
- **运河砖城 fort 昼夜拉锯**（台儿庄）：(5,9) fort 2 起始、逐回合削减、夜间免费夺回——据点状态。
- **诱敌深入补给衰减**（台儿庄）：让开正面→蓝补给线延长、T6 合围补给衰减。
- **外线反击解锁**（台儿庄）：汤军团 T1—T5 隐蔽(敌不可见)、T6 入场拊侧背——单位显隐状态。
- **南北对进双轴 + 五路突围**（徐州）：双集群分速加成、会师士气脉冲、四条突围路线封锁线掷骰。
- **龙亭核心攻坚特则**（豫东）：城内核心 fort 加层，需炮火准备+尖刀突击。

## F. 落地优先级建议（待引擎排期）

1. **P0（影响最多剧本、语义最清晰）**：A1 `withdraw` 突围胜利 + A2 主动弃守不判负 → 直接解锁徐州/中条山/九一八的史实终局。
2. **P0**：C 事件框架（回合事件表 + 抽取 + 效果结算）→ 解锁全部"外围纵深事件链"与具名事件卡。
3. **P1**：B 全局规则框架（行动约束/状态机）→ A3 不抵抗枷锁、斩首、枢纽拦截。
4. **P1**：E 单位状态机（坑道态/显隐/fort 拉锯）→ 上甘岭、台儿庄、石牌核心体验。
5. **P2**：D 多图/分图切换 → 武汉、徐州大图幅还原（可用事件卡或向导框选先行缓解）。
