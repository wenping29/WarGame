# 抗美援朝第四次战役回合阶段与师级部署（1951.1.25 — 4.21）

> 用途：兵棋剧本《抗美援朝第四次战役 1951》（`korea_c4_1951.json`，东线横城反击与运动防御）编制参考；西线汉江阻击另有专剧本 `hanjiang_1951.json` 可衔接。坐标为 WGS84 度（经度E, 纬度N），朝鲜半岛地名取城镇/高地约 1—2km 内近似锚点（公开战史多精确到团/高地级，师段位为防区中心）。
> 史实来源：中国军网《横城反击战：穿插迂回作战教科书》、央视网《志愿军抗美援朝战争大事记(1951)》及《回顾志愿军抗美援朝五大战役》、退役军人事务部《志愿军横城大反击》、中国军网《第四次战役中我军动态防御予敌重创》、中国法院网《抗美援朝战争第四次战役》交叉核对。

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1951年1月25日（敌发起全线反扑）— 4月21日（敌被阻于三八线附近停止进攻），共 **87 天**——抗美援朝战争史上唯一一次大规模防御战役 |
| 战场 | **西线**：汉江南北（修理山、帽落山、光教山、白云山、350.3 高地—京安里）钳制敌主攻集团；**东线**：横城—砥平里—洪川—原州（横城反击主战场）；后期全线运动防御退至三八线 |
| 中朝联军 | 志愿军一线 21 万人（连续三役未及休整、粮弹未补）。**西线韩先楚集团**：38/50 军 + 人民军 1 军团坚守防御；**东线邓华集团**：39/40/42/66 军（11 个师欠 1 团，563 门炮）+ 人民军 2/3/5 军团反击。第二番兵团（19 兵团杨得志 2 月中旬、3 兵团陈赓 3 月中旬）先后入朝集结 |
| 联合国军 | 李奇微集中 **23 万余人**（美军 7 个师、南朝鲜军 8 个师、英军 2 个旅）全线反扑；战术已变——"磁性战术"黏住消耗、"火海战术"火力制胜、夜间后撤白天反攻；连续实施"霹雳"（1.25）、"屠夫"（2.21）、"撕裂者"（3.7）、"狂暴"行动 |
| 战役方针 | 积极防御（坚守防御 + 战役反击 + 运动防御相结合）：西线依托野战工事顶住敌主攻，东线诱敌突出后横城反突击；砥平里受挫后 2.17 全线转运动防御，**以空间换时间**，掩护二番兵团集结（前轻后重、逐次抵抗、数道防御阵地轮番换班） |
| 最终结果 | 歼敌 **7.8 万余人**（我方伤亡 4.2 万余人，敌我伤亡比 1:0.67；敌日均伤亡 900 人仅前进 1.3—1.5km）；横城反击歼韩8师 3 个团及韩3/5 师、美2师各一部 1.2 万余（俘韩军 7500、美军 500——单次俘敌之最）；砥平里攻坚受挫（暴露火力/补给弱点）；汉江阻击敌 14 天仅前进 18km 伤亡 1 万余；3.14 主动撤出汉城，4.21 敌被阻于开城—涟川—芝浦里—华川—杨口—杆城一线，为第五次战役创造了条件 |
