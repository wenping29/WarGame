# 淮海战役回合阶段与师级部署（1948.11.6 — 1949.1.10）

> 用途：兵棋剧本《淮海战役 1948》编制参考。坐标为 WGS84 度（经度E, 纬度N），取城镇/阵地近似锚点。
> 回合制：剧本模板 `huaihai_1948.json` max_turns = 16，战役 66 天，每回合 ≈ 4 昼夜（末段总攻阶段细化到 1–2 天）。
> 史实来源：求是网《毛泽东选集》第四卷注释、人民网党史频道、邯郸党史网、商丘日报等交叉核对。
> 注：解放军师级坐标为纵队作战正面内的展开近似锚点（公开史料精确到纵队级任务地段），国军师驻地按史料记载。

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1948.11.6 — 1949.1.10，历时 66 天 |
| 战场 | 以徐州（117.18,34.26）为中心，东起海州（119.17,34.60）、西至商丘（115.65,34.41）、北起临城（117.27,34.80）、南达淮河 |
| 解放军 | 华野 16 个纵队 + 中野 7 个纵队 + 军区地方武装，共约 **60 万**（另有 543 万民工支前） |
| 国民党军 | 徐州"剿总"（刘峙任总司令，杜聿明实际指挥）4 个兵团 + 华中驰援黄维兵团，共 5 个兵团约 **80 万** |
| 总前委 | 刘伯承、陈毅、邓小平、粟裕、谭震林（邓小平为书记），11.16 成立，驻安徽濉溪临涣集（116.63,33.74）→ 河南商丘张菜园（115.55,34.35） |
| 性质 | 三大战役中**唯一以少胜多**、歼敌最多（55.5 万）的战略决战 |
| 最终结果 | 歼敌 55.5 万余（5 个兵团部、22 个军部、56 个师），解放军伤亡 13.4 万；长江以北华东、中原基本解放，南京直接暴露 |
