# 渡江战役兵要资料（1949年4月20日 — 6月2日）

> 用途：兵棋剧本《渡江战役》编制参考。坐标为 WGS84 度（经度E, 纬度N），取城镇驻地/渡江地段近似值。
> 史实来源：人民日报《渡江战役：百万雄师过大江》、中央党史和文献研究院《第三野战军的渡江作战》、学习时报、渡江战役总前委条目交叉核对。

---

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1949年4月20日夜（中集团率先渡江）— 6月2日（解放崇明岛），历时 42 天 |
| 背景 | 4月20日南京政府拒绝《国内和平协定》；21日毛泽东、朱德发布《向全国进军的命令》 |
| 解放军总兵力 | 第二、第三野战军 7 个兵团 24 个军及地方部队约 **100 万人**，另有第四野战军先遣兵团策应 |
| 国民党军总兵力 | 宜昌—上海 1800 余公里江防线，**115 个师约 70 万人** + 海军 2 舰队 133 艘舰艇 + 空军 4 个大队约 300 架飞机 |
| 总前委 | 刘伯承、陈毅、邓小平、粟裕、谭震林（邓小平为书记），驻合肥东郊肥东县**瑶岗村**（117.47E, 31.88N） |
| 战役纲领 | 1949年4月3日《京沪杭战役实施纲要》 |
| 最终结果 | 歼敌 **43 万余人**，占领南京、上海、杭州、武汉、南昌，解放苏南、皖南、浙江全省及赣、鄂、闽部分地区，国民党"划江而治"破产 |

- 总部：汉口（114.31, 30.59）
- 江防正面：湖口—武汉—宜昌
- 海军：海防第2舰队 89 艘（长江下游，驻南京一带）；江防舰队 44 艘（长江中游）

- 另有美英舰艇泊上海吴淞口外（4月20日"紫石英号事件"发生于三江营江面 119.60,32.29）

## 四、三阶段进程（兵力位置推移）

### 第一阶段：突破江防，占领南京（4月20日夜 — 4月23日）

| 日期 | 行动 | 双方位置（E, N） |
|---|---|---|
| 4月20日夜 20:00 | **中集团率先**由裕溪口—枞阳段强渡，一夜突破；当日三江营江面发生**紫石英号事件** | 中集团：无为江坝 118.30,31.44 → 南岸繁昌 118.20,31.08、铜陵方向；当面之敌：第88军（铜陵）、第20军（芜湖） |
| 4月21日 | 毛泽东、朱德发布《向全国进军的命令》；**黄昏，东集团**（三江营—张黄港）与**西集团**（枞阳—望江）同时强渡 | 东集团：江阴两侧登陆，进占江阴要塞（120.28,31.91，要塞起义）；西集团：登陆东流、至德以南，攻安庆侧背；当面之敌：第54军预备队北援不及 |
| 4月22日 | 三大集团全部过江，纵深推进30—70公里；汤恩伯下令总退却：南京—镇江之敌向杭州、上海收缩，铜陵以西向浙赣线收缩 | 中集团前锋抵宣城（118.76,30.95）；东集团控制宁沪铁路；西集团占贵池（117.49,30.66）、青阳（117.85,30.64） |
| 4月23日 | **南京解放**（35军进占总统府）；34军占镇江；中集团占芜湖；四野先遣兵团占黄梅、浠水、汉川 | 解放军：南京 118.80,32.06、镇江 119.43,32.19、芜湖 118.38,31.35；国军第28/45/99军向浙赣线溃退 |

**阶段结果**：一夜之间突破千里江防，歼灭江防一线守军大部，南京（国民政府首都）易手。

### 第二阶段：合围歼敌，控制浙赣线（4月24日 — 5月11日）

| 日期 | 行动 | 双方位置（E, N） |
|---|---|---|
| 4月24—29日 | 东、中集团东西对进追击，在**郎溪—广德**间完成合围，歼敌 5 个军 **8 万余人**（含第4、20、28、51、66军等） | 合围圈：郎溪 119.18,31.13、广德 119.42,30.89；被围国军自南京—芜湖方向南逃至此后就歼 |
| 5月3日 | 7兵团（21/22/24军）**解放杭州** | 解放军：杭州 120.16,30.27；残敌向浙东、福建溃退 |
| 5月4—7日 | 西集团控制**义乌—东乡段 400 余公里浙赣线**，切断汤、白两大集团联系 | 二野3兵团：金华 119.65,29.10；4兵团：上饶 117.94,28.45、东乡 116.59,28.24；5兵团向闽北推进 |
| 同期 | 7兵团向浙东、浙南进军；8兵团警备南京、镇江；9/10兵团8个军东进围上海；四野先遣兵团逼近武汉 | 围城兵团集结：苏州 120.62,31.30、嘉兴一线 |

**阶段结果**：歼敌 8 万余人于郎广地区；占领杭州；浙赣线贯通敌纵深被截断，国军华东主力仅剩上海方向。

### 第三阶段：攻占上海，进占武汉、南昌（5月12日 — 6月2日）

| 日期 | 行动 | 双方位置（E, N） |
|---|---|---|
| 5月12—25日 | 三野 9/10兵团发起**上海战役**：先取外围（浦东、吴淞侧背），攻坚阵地逐次推进 | 国军8个军20余万守上海：吴淞 121.50,31.39、南翔 121.32,31.30、浦东 121.60,31.25；解放军合围圈：昆山—嘉善一线 |
| 5月16—17日 | 四野先遣兵团（12兵团）渡江，**解放武汉三镇**（16日汉口，17日武昌、汉阳） | 解放军：汉口 114.31,30.59；白崇禧部撤往湖南（长沙方向） |
| 5月22日 | 二野第4兵团（陈赓）**解放南昌** | 解放军：南昌 115.86,28.68；残敌南撤赣南 |
| 5月27日 | **上海解放**，歼敌 15 万余人（汤恩伯率约5万经海路撤往舟山、台湾） | 解放军：上海市区 121.47,31.23 |
| 6月2日 | **解放崇明岛**（121.40,31.62），渡江战役结束 | 苏南、皖南、浙江全省及赣东北、鄂东全部解放 |

**阶段结果**：歼敌15万于上海，华东最大城市与经济中心易手；武汉、南昌相继解放。

## 五、最终结果

| 项目 | 数值 |
|---|---|
| 历时 | 42 天（1949.4.20 — 6.2） |
| 歼敌总数 | **43 万余人**（含郎广围歼 8 万、上海 15 万） |
| 解放城市 | 南京、上海、杭州、武汉（三镇）、南昌、芜湖、镇江、安庆、九江等 |
| 解放区域 | 苏南、皖南、浙江全省，江西东北部、湖北东部、福建部分地区 |
| 国军损失 | 京沪杭警备总部主力覆灭；仅汤恩伯率残部约5万自上海海运撤退 |
| 战略意义 | 宣告国民党22年统治覆灭（南京易手），粉碎"划江而治"，为解放全中国奠定基础 |
