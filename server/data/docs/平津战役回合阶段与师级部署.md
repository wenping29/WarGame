# 平津战役回合阶段与师级部署（1948.11.29 — 1949.1.31）

> 用途：兵棋剧本《平津战役》编制参考。坐标为 WGS84 度（经度E, 纬度N），取城镇/阵地近似锚点。
> 回合制：剧本模板 `pingjin_1949.json` max_turns = 12，战役 64 天，每回合 ≈ 5.3 昼夜。
> 史实来源：央视网《永远的丰碑·平津战役》（据新华社）、人民网党史频道、共产党员网交叉核对。
> 注：解放军师级坐标为军（纵队）作战正面内的展开近似锚点（公开史料精确到军级任务地段），国军师驻地按史料记载。

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1948.11.29 — 1949.1.31，历时 **64 天** |
| 战场 | 平绥线（张家口—北平）与北宁线（北平—天津—塘沽—唐山）交汇的华北平原北部，东起滦县（118.75,39.89）、西至柴沟堡（114.35,40.68）约 500 公里铁路沿线 |
| 解放军 | 东北野战军（林彪、罗荣桓，参谋长刘亚楼）2 个兵团部、13 个纵队、特种兵司令部共 80 余万 + 华北军区第 2、3 兵团（杨得志、杨成武）7 个纵队 13 万余，**总计约 100 万** |
| 国民党军 | 华北"剿总"（总司令**傅作义**，北平）4 个兵团 12 个军 42 个师(旅)，**50 余万**，沿铁路摆"一字长蛇阵"；蒋系 3 兵团 8 军 25 师守北平以东至塘沽，傅系 1 兵团 4 军 17 师守北平以西至张家口 |
| 方针 | "围而不打"（张家口、新保安）、"隔而不围"（平、津、塘、唐），先打两头、后取中间，抑留傅集团于华北就地解决 |
| 最终结果 | 歼灭和改编 **52.1 万**（1 个"剿总"总部、3 个兵团部、13 个军部、51 个师），解放军伤亡 3.9 万；北平**和平解放**创"北平方式"；华北大部分地区解放 |
