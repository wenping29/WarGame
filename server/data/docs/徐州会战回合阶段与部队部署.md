> 关联文档：《台儿庄战役回合阶段与部队部署》（台儿庄阶段为本文 T5—T6 的展开，互为衔接）

## 一、战役概况

- **战略背景**：日军攻占南京、济南后，为打通津浦铁路使南北战场连成一片，调集 **8 个师团另 3 个旅团、2 个支队约 24 万人**，由华北方面军司令官寺内寿一与华中派遣军司令官畑俊六指挥，**南北对进**夹击徐州；得手后沿陇海线西取郑州、沿平汉线南夺武汉
- **中方兵力**：第五战区司令长官李宗仁，先后调集 **64 个师另 3 个旅约 60 万人**（后期增至约 70 个师、100 万人次），主力集中于徐州以北，一部部署于津浦路南段
- **总体进程**：三阶段——①津浦路沿线初期保卫战（1937.12—1938.2，淮河阻击 + 鲁南对峙）；②台儿庄战役（1938.3—4，歼敌万余大捷）；③徐州附近作战与突围（1938.4 下旬—5，日军改为主力西迂回大合围，中方 5.15 决定放弃、16 日五路突围、19 日徐州陷落）
- **战果**：中方伤亡约 6.5 万—10 万，毙伤日军 **2.6 万余**；日军虽打通津浦线、占据空城徐州，但**围歼中国军队主力的企图完全落空**——李宗仁"化整为零"成功突围 60 万大军，为武汉会战赢得部署时间；会战末期花园口决堤形成黄泛区，日军被迫改道，**抗战全面转入战略相持的轨道由此奠定**
- **战略评价**：打破日军"南北会师、致命一击"的钳形企图；台儿庄大捷开了正面战场胜利之先河；60 万大军在合围中全身而退，是抗战史上规模最大、组织最成功的战略转移

## 五、模板对应与修正建议

1. **图幅与史实吻合度**：26×20 格 5km、中心 117.2/34.3 → 覆盖约 116.4—118.0E / 33.85—34.75N，即**徐州—台儿庄—韩庄—萧县—砀山东部—沛县—禹王山**核心区；滕县、临沂、蚌埠、蒙城、永城、宿县、兰封、金乡、菏泽等全部在图外——建议仿《武汉会战》方案，外围战场以**回合事件卡**呈现（T4 临沂/滕县、T9—T11 西迂回四路、T15 兰封），或采用"徐州核心 + 鲁南 + 淮北"多图体系
2. **⚠ 蓝方 OOB 方位错误（与淞沪/南京等模板同一通病）**：蓝方 HQ 与红方同格 (2,10)、全线部署于西侧 1—6 列与红方重叠；史实日军为**南北对进**——建议蓝方拆为两路 OOB：**北集群 HQ (14,3)**（峄城—台儿庄方向，第 10/5 师团）、**南集群 HQ (14,18)**（宿县—蚌埠方向，第 13/3 师团），T9 起西翼合围部队自北 (14,2)、南 (14,19) 图外入场；红方则围绕徐州城格 (5,10) 配置

## 六、建议机制

1. **南北对进双轴事件**：蓝方北/南两集群分速能力加成，两军会师（历史 T7 目标）给予士气脉冲——呼应"打通津浦线"
2. **外围纵深事件链**：T4 临沂/滕县（红方成功迟滞→台儿庄战机；失败→北钳提前压至）、T9—T11 西迂回四路（第 14 师团兰封封口判定）、T15 兰封会战
3. **反包围警觉钟**：T9 起蓝方主力转向西迂回；红方须在 T13 前把主力单位撤至图西/南边缘，滞留徐州的单位按合围判定歼灭——复现"5.15 最后窗口"
4. **五路突围特则**：突围路线四条（沿津浦南下/符离集西越/萧县西南/陇海路西北）各自有封锁线掷骰，李庄遭遇战（关麟征路）给一次性反杀加成；68 军后卫单位可迟滞蓝方 2 回合
5. **禹王山事件**：60 军（滇军）在鲁南东翼获得山地防御加成与"血战 27 昼夜"迟滞计数，成功迟滞可为突围争取回合
6. **空城计计分**：徐州陷落时红方残留单位越少、突围单位越多，红方得分越高——突出"日军以万余伤亡得一空城"的史实讽刺
7. **花园口决堤叙事收尾**：T16 强制事件，蓝方西进路线冻结、红方黄泛区以西再无追兵——衔接武汉会战剧本
