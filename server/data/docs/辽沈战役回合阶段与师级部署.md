# 辽沈战役回合阶段与师级部署（1948.9.12 — 1948.11.2）

> 用途：兵棋剧本《辽沈战役 1948》编制参考。坐标为 WGS84 度（经度E, 纬度N），取城镇/阵地近似锚点。
> 回合制：剧本模板 `liaoshen_1948.json` max_turns = 16，战役 52 天，每回合 ≈ 3.25 昼夜。
> 史实来源：中国法院网战史、澎湃《每日一典》（新华网/共产党员网）、海口市档案馆、青岛党史研究院《中国共产党简史》交叉核对。
> 注：解放军师级坐标为纵队作战正面内的展开近似锚点（公开史料精确到纵队级任务地段），国军师驻地按史料记载。

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1948.9.12 — 1948.11.2，历时 **52 天** |
| 战场 | 北宁线（山海关—沈阳铁路）两侧：北起长春（125.32,43.88），南至山海关（119.75,40.01），东起沈阳（123.43,41.80），西抵绥中（120.34,40.41） |
| 解放军 | 东北野战军（林彪、罗荣桓）12 个纵队 + 1 个炮兵纵队 + 各独立师共 53 个师，**约 70 万**（连同地方武装 103 万） |
| 国民党军 | 东北"剿总"（总司令**卫立煌**）+ 副总司令范汉杰（锦州）、郑洞国（长春），4 个兵团 14 个军 44 个师（旅），约 **55 万** |
| 方针 | 《关于辽沈战役的作战方针》：主力南下北宁线，**攻锦"关门"，把敌封闭在东北就地歼灭** |
| 最终结果 | 歼敌 **47.2 万**（36 个整师），解放东北全境；解放军在此后数量上首次超过国民党军，东北成为巩固的战略后方 |
