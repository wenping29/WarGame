## 一、事变概况

| 项目 | 内容 |
|---|---|
| 起止 | 1937年7月7日 19:30（日军演习）— 7月30日（天津失守、平津沦陷），共 **24 天**——**全国性抗战（全面抗战）由此爆发** |
| 事变爆发 | 7.7 19:30 日军中国驻屯军步兵旅团第1 联队第3 大队第8 中队（清水节郎）荷枪实弹进至第29 军防区宛平东北**回龙庙—大瓦窑**一带挑衅演习；深夜自称一名士兵"失踪"（志村菊次郎，20 分钟后已归队仍被隐瞒），驻北平特务机关长松井太久郎电话要求进入宛平城搜查被拒——交涉未毕即炮轰宛平、进攻卢沟桥 |
| 打响第一枪 | 7.8 凌晨 5 时日军包围宛平并发起攻击；守卫卢沟桥、宛平城的第29 军 **37 师 109 旅 219 团**（团长**吉星文**，3 营营长**金振中**守桥）奋起还击——**全面抗战第一枪** |
| 中方态势 | 第29 军（军长宋哲元，约 10 万人，喜峰口大刀队旧部）：37 师（冯治安）驻北平西苑—卢沟桥一线、38 师（张自忠）驻天津—廊坊、132 师（赵登禹）由河间调南苑、143 师（刘汝明）驻察哈尔。7.8 中共中央通电全国"平津危急！华北危急！中华民族危急！"；7.9 蒋介石令调兵向石家庄、保定集中；7.17 庐山谈话"如果战端一开，那就是地无分南北，年无分老幼……皆应抱定牺牲一切之决心" |
| 日方态势 | 中国驻屯军（司令官田代皖一郎，7.11 由**香月清司**接任，7.16 田代病死）驻屯步兵旅团（河边正三）第1 联队（牟田口廉也）驻丰台——约 5700 余人；借"和平谈判"争取时间，7.11《派兵华北声明》后关东军独立混成第1/11 旅团、朝鲜军第20 师团及第5/6/10 师团陆续入关，三周增至约 10 万 |
| 谈判周旋 | 7.9—7.25 间"秦德纯—松井协定"等假停火屡签屡毁；宋哲元一度幻想"局部解决"中敌缓兵之计，未及集中兵力、未做北平弃守预案——为 7.28 突然溃败埋因 |
| 最终结果 | 7.25 廊坊事件、7.26 广安门事件、日军最后通牒被拒；**7.28 总攻南苑**，守军伤亡 2000 余，副军长**佟麟阁**、132 师师长**赵登禹**壮烈殉国（抗战中最早牺牲的两名高级将领）；7.29 北平陷落（同日通州冀东伪保安队反正杀日侨）、7.30 天津失守——平津沦陷，日军转入沿平汉/津浦/平绥三线进攻，全面侵华战争全面展开 |
