# 抗美援朝第五次战役回合阶段与师级部署（1951.4.22 — 6.10）

> 用途：兵棋剧本《抗美援朝第五次战役 1951》（`korea_c5_1951.json`）编制参考。坐标为 WGS84 度（经度E, 纬度N），朝鲜半岛地名取城镇/高地约 1—2km 内近似锚点（公开战史多精确到团/高地级，师段位为防区中心）。
> 史实来源：中国军网系战史《抗美援朝第五次战役敌我双方兵力之和超过百万》、百度百科《抗美援朝战争第五次战役》《县里围歼战》、青岛新闻网/湖南日报《铁原阻击战》（电影《志愿军：存亡之战》史实背景）交叉核对。

## 一、战役概况

| 项目 | 内容 |
|---|---|

| 战场 | **第一阶段西线**：临津江—绀岳山—雪马里—议政府轴（汶山至春川间主要突击）；**第二阶段东线**：昭阳江—县里—砧桥围歼场；**第三阶段**：北汉江两岸转移危机 + 涟川—铁原—华川阻击线 |

| 三阶段 | **①西线突击**（4.22—29）：雪马里全歼英29 旅格洛斯特营，但发展成平推歼敌不多，4.29 停攻；**②东线县里围歼**（5.16—21）：歼韩3/9 师大部、溃韩5/7 师，歼敌 2.3 万余，粮弹将尽 5.21 停攻；**③转移与阻击**（5.23—6.10）：敌 4 个军 13 个师全线反扑，180 师遭重大损失，铁原/华川阻击稳住战线 |
| 最终结果 | 歼敌 **8.2 万余人**（志愿军歼 6.7 万余）；我伤亡 7.5 万、战斗减员 8.5 万（180 师损失 7600 余）；6.10 主动撤出铁原、金化，战线稳定于**汶山—涟川—铁原—金化—杨口—明波里一线**；敌占领全朝鲜企图彻底破灭、转入战略防御——**朝鲜战争进入两年战略相持，7.10 开城停战谈判开始**（打谈结合时代） |
