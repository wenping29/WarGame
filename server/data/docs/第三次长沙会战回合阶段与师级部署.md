# 第三次长沙会战回合阶段与师级部署（1941.12.24 — 1942.1.15）

> 用途：兵棋剧本《第三次长沙会战 1941》编制参考。坐标为 WGS84 度（经度E, 纬度N），取城镇/阵地近似锚点。
> 回合制：剧本模板 `changsha_1941.json` max_turns = 14，战役 23 天，每回合 ≈ 1.7 昼夜。
> 史实来源：湖南省文史研究馆《试论长沙会战的历史意义》、中国军网（新华社）、中新网《薛岳"天炉战法"》等交叉核对。
> 注：师级坐标为军/师团作战正面内的展开近似锚点（公开史料精确到军/师团级任务地段），战斗详报中的具体阵地按史料记载。

## 一、战役概况

| 项目 | 内容 |
|---|---|
| 起止 | 1941.12.24 — 1942.1.15，历时 **23 天**（12.23 日军开始炮击新墙河防线） |
| 战场 | 湘北：新墙河（113.25,29.15）—汨罗江（113.08,28.81）—捞刀河/浏阳河（113.00,28.32 / 113.09,28.13）—长沙（112.94,28.23） |
| 日军 | 第 11 军（司令官**阿南惟几**，驻汉口 114.30,30.59）：第 3、6、40 师团 30 个大队约 **6 万** + 军直属队 + 第 1 飞行团一部（40 余架），为策应香港作战的牵制性进攻 |
| 中国军队 | 第九战区（司令长官**薛岳**，长沙）：约 **30 个师 30 万** |
| 战法 | **"天炉战法"**：新墙河、汨罗江间为伏击/诱击地带，捞刀河、浏阳河间为决战地带；守城部队如磁石吸敌，外线兵团反包围 |
| 最终结果 | 中方战报毙伤俘日军 **5.69 万**（日方自认约 6000，学界采中）；中国伤亡 2.8 万。**太平洋战争爆发后盟军对日首场重大胜利**，英国《每日电讯报》称"长沙上空之云彩确见光辉夺目"；战后美国宣布对华 5 亿美元贷款、英美宣布废约，蒋介石出任中印缅战区盟军最高统帅 |

## 五、与剧本模板对应

- **回合数**：模板 `changsha_1941.json` `max_turns: 14` ↔ 上表 T1–T14（每回合约 1.7 天）。
- **环境**：模板 `clock: start_hour 7, season 冬`、`weather.initial overcast` 吻合（湘北冬季阴雨泥泞，日机械化与空投受限）；建议天气计划：T1–T4 阴雨（阻敌摩托化行军）→ T5–T7 多云（攻城）→ T8–T13 阴雨（追击泥泞拖累日军重装备）。
- **图幅**：战场纵深受湘北—长沙约 113 km（新墙河 29.15N → 长沙 28.23N）、横跨 112.8–113.7E（含浏阳方向）。建议框选 **112.7–113.8E / 27.7–29.5N**（1.1° × 1.8°，对边距 2500m 约 1.7 万格，完全可行——含株洲湘潭纵深与岳阳出发地）。
- **棋子规模**：中方约 20 个师 + 军部 6 + 战区部 1，日方 3 个师团 + 旅团 + 直属 ≈ 35 棋子，与模板红/蓝点数预算量级接近，**可直接按师级建棋**。
- **战果数据分歧提示**：歼敌数中方战报 5.69 万、日方自认约 6000，剧本胜负判定建议以"日军是否退过新墙河 + 攻克长沙与否"为核心条件而非歼敌数。
